# TapManía · Burger Boom

Juego de reflejos para móvil y escritorio. Encuentra el animal, color o número indicado antes de que explote la hamburguesa.

- La mecha empieza en 6 segundos. Cada acierto suma puntos y repone parte del tiempo, hasta el máximo de 6 segundos.
- El tiempo que devuelve cada acierto disminuye a medida que avanza la partida. Cada error resta 1,2 segundos y reinicia el combo.
- Las rachas multiplican los puntos hasta ×5. El récord se guarda en el navegador.
- Juega tocando las fichas o pulsando su tecla visible (1–9, Q, W, E).

Abre `index.html` para jugar localmente. El juego usa HTML, CSS y JavaScript sin dependencias. GitHub Pages sirve la raíz de `main`.
